`미리보기_*.png` 는 일러스트레이터 없이도 눈으로 확인하시라고 함께 둔
것입니다. 150dpi 로 뽑았습니다. 쓰실 때는 `.ai` 원본을 쓰세요.

## 홈페이지에 쓰는 로고와 다릅니다

홈페이지 머리띠와 꼬리말에 나가는 것은 `public/` 에 있는 SVG 입니다.

    public/logo-kba-wide.svg   머리띠 (가로형)
    public/logo-kba.svg        꼬리말·증명서 (세로형)
    public/favicon.svg         브라우저 탭
    public/og-image.png        카톡·페북 공유 그림

여기 있는 `.ai` 는 굿즈(수건·가방·배지 따위)용 원본이라 홈페이지에서
불러 쓰지 않습니다. 그래서 `public/` 이 아니라 이 폴더에 둡니다. 한 개가
1MB 가 넘어, 홈페이지에 두면 방문자가 쓰지도 않을 파일을 받게 됩니다.
